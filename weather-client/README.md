# Weather App – Frontend

A modern weather application built using **React + TypeScript** that allows users to search for current weather and a 5-day forecast by city.

## Features
- Search weather by city name
- View current temperature and conditions
- 5-day weather forecast
- Weather icons from OpenWeather
- Error handling with toast notifications
- Clean, centered UI using CSS Modules
- Fully typed with TypeScript

## Tech Stack
- React
- TypeScript
- Vite
- Axios
- CSS Modules
- react-hot-toast
